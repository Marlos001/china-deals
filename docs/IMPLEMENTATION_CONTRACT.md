# Initial implementation contract

Project: `china-deals`, Python 3.11+ stdlib core, MIT. No LLM API calls. External authenticated marketplace adapter: OpenCLI 2.0.2 (Apache-2.0), pinned source 97dc0cd5214b9602bcda78d7422f231ee8a803e9. Agent subscriptions provide reasoning/translation externally. User clarified Blibli Indonesia, NOT Bilibili. Fansbuy is https://fansbuy.com/.

Ownership: root owns package config, models.py, ranking.py, cli.py, docs, examples. Marketplace worker owns adapters.py and tests/test_adapters.py; shipping worker owns shipping.py and tests/test_shipping.py. Do not alter others' files without coordination. No commits/push by workers.

All public functions return JSON-serializable dictionaries; monetary values decimal strings, not floats. Exceptions use `ValueError` for invalid inputs. Network/backend failures must become structured status in marketplace search (not silently zero results). Network shipping errors can raise ValueError with actionable generic error, no cookies or raw private data.

`adapters.search_marketplace(marketplace: str, query: str, limit: int = 10, timeout: float = 90, executable: str = 'opencli') -> dict`: `{marketplace,status,items: [dict],warnings:[str],error: null|{code,message}}`. canonical marketplace taobao, jd, goofish, blibli. statuses ok, empty_unverified, blocked, auth_required, unavailable, error. Items normalized by root `models.normalize_offer(marketplace, row, observed_at=None)`; worker may return raw rows and root will normalize. Blibli may be direct public JSON endpoint with structured 403. Implement optional browser extraction fallback via OpenCLI only if contracts verified; no generic shell strings, no CAPTCHA solving. `adapters.get_item(marketplace, item_id, timeout=90, executable='opencli') -> dict` same envelope. `adapters.doctor(executable='opencli', live=False) -> dict` basic availability/version; live bridge check only with explicit live.

`shipping.fansbuy_quotes(weight_g, dimensions_cm=None, categories=None, timeout=30) -> dict`: `weight_g` positive number, dimensions optional length-3 positive tuple. categories list uses frontend names Electric, Brand, liquid, bag, food, shoes, Battery, Knives, powder, watch, cosmetics, magnetic, perfume. Public POST https://fansbuy.com/apiv2/web/cart/checkarea {serch:'hot'} dynamically resolve BR; POST /apiv2/estimatesTest {weight:grams,volume:length*width*height or 0,currency:'CNY',price:0,country:str(region_id)}. Source website JS observed by root in .local/research. Stored real no-auth response: .local/research/fansbuy-browser-live.json or fansbuy-estimatesTest.json. API returns disabled routes too; filter/report rejected. Respect special flags, min/max weight, dimensions (max_anySide/max_sumSide) and all ambiguous constraints conservatively. Preserve route quote source/time, currency CNY, travel_time, quote kind and warnings. Do not assume coupon discount eligible. Expose base total_fee; discount_display is conditional. No inference that battery needs sea or that sea fixes legal prohibitions. `shipping.estimate_landed_cost(goods_cny, freight_cny, cny_brl, usd_brl, icms_rate, domestic_cny='0', agent_fee_cny='0', insurance_cny='0', remessa_conforme=False) -> dict`: user-supplied positive FX, explicit ICMS; conservative non-PRC default, mark all exclusions and not official quote, reject customs value > USD3000 instead of pretending RTS valid. Check current source before PRC thresholds. `shipping.assess_import(condition='unknown', categories=None, ncm=None) -> dict`: conservative manual review and sources, no legal clearance inferred.

Root CLI commands: search, detail, rank (offline supplied JSON), shipping (live or captured response), estimate, restrictions, doctor, schema. JSON default, optional human Markdown. Normalized offer preserves native currency (IDR for Blibli; CNY others), original price, ID, canonical URL, observation time, unknown variant/condition and seller trust. Lowest displayed prices only, never claim verified best deal or compare different currencies without explicit FX. Distinguish Blibli Indonesia -> Brazil logistics from China -> Fansbuy; no automatic Fansbuy eligibility for Blibli.
