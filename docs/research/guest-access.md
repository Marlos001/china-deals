# Guest access to Chinese marketplace search and listing details

Research snapshot: 2026-10-27 (Brazil). Scope: no Taobao, JD, Goofish or Blibli accounts; Fansbuy is the buying agent. No signup, user cookies, CAPTCHA, security-control bypass, purchase, contact, extension installation or publishing. Blibli is researched separately. Browser observations below are from a new T3 Preview Incognito tab; guest-generated site state is distinct from an authenticated user cookie. Results depend on network, region, site rollout and time.

## Decision

1. **Use Goofish public item URLs when independently discoverable.** A live guest browser loaded the actual [ROG 幻16 Air listing 985148706040](https://www.goofish.com/item?categoryId=126854525&id=985148706040), including seller description and structured specifications, without an account or extension. This specific item is **已下架 (delisted)**, not a purchase opportunity. Use public search-engine indexing as a discovery lead, then check the source item and its current availability before passing its exact link to Fansbuy. Search-engine snippets can be stale; they are not proof of current price, stock or seller claims.
2. **Native Goofish guest keyword search is not a working catalog path in this test.** Both `ROG 幻16` and `幻16` loaded the native filter shell, then said no items were found, followed by unrelated 猜你喜欢 recommendations. Do not ingest recommendations as keyword results or infer there are no matching listings. A separate anonymous direct mtop probe returned `RGV587_ERROR` and a login/security URL despite HTTP 200; stop on that signal, do not retry or route around it. A missing signature or guest state may also affect the probe; this does not prove all anonymous mtop access is impossible. Browser-to-API is a research candidate only, not an established guest integration.
3. **Taobao search and JD search were not proven usable here.** Taobao desktop rendered controls but remained loading with no item links in the observation; the separately requested mobile search URL returned 404. JD desktop search redirected to 京东验证 and then login; no challenge was attempted. These observations do not establish global policy. For Taobao/Tmall/1688, [Fansbuy's own guide](https://fansbuy.com/beginnerGuide) describes product-name search as well as pasting a source link; its home page advertises JD access. Its actual coverage, filters, link acceptance and available price for a particular listing still need a read-only check. The agent model makes a marketplace account optional for a link-based purchase workflow; it does not make Fansbuy's inventory a complete native search index.

## Native filter contract and implementation boundaries

The UI should expose **unknown / blocked** when a provider does not return a validated result set, preserve the original listing URL and source timestamp, and keep marketplace ranking separate from local post-filtering. Query aliases separately: `ROG 幻16`, `幻16 Air`, `华硕 幻16`, `ROG Zephyrus G16`, and model/SKU such as `GU605`; verify generation and model from the listing rather than assuming the names are exact synonyms. Exclude obvious laptop bags, rentals, deposits and parts only with explicit labels; do not silently discard ambiguous matches.

| Intent | Goofish native web / observed or source-documented wire format | Taobao / JD |
|---|---|---|
| Keyword/model | `https://www.goofish.com/search?q=<URL-encoded keyword>`. No model facet demonstrated; keyword plus item `型号` is the safe approach. | Taobao `q=<keyword>`; JD `keyword=<keyword>`. Model-facet IDs are category- and response-dependent; no stable contract was verified. |
| Price | Web has two ¥ inputs. OpenCLI sends `propValueStr.searchFilter="priceRange:<min>,<max>;"` in yuan; omitted lower bound becomes `0`, omitted upper `99999999`. | Taobao documented `startPrice`, `endPrice` in yuan; source requires authenticated browser. JD range controls/parameters not verified. |
| Sort | Web labels 综合, 新降价, 新发布, 价格. [goofish-client types](https://github.com/11273/goofish-client/blob/30b153653588d4d4e1d9038290b1e968525e5be4/src/types/mtop/search.ts) specify `sortField=price/create/reduce/pos/modify/credit`, `sortValue=asc/desc/credit_desc`; combinations are not all proven supported. | [Taobao browser workflow](https://github.com/browser-act/skills/blob/main/solutions/ecommerce/taobao-keyword-search/SKILL.md) documents `sort=price-asc`, `price-desc`, `sale-desc`, or empty; no guest verification. JD UI/parameter mappings not verified. |
| Location | `extraFilterValue` is a **JSON string** containing `divisionList:[{province,city}]`; OpenCLI accepts either name alone. Client type additionally defines `area`, `excludeMultiPlacesSellers` and `extraDivision`; builder serializes exclusion as `"1"`/`"0"`. | Taobao shows 发货地; exact values/URL contract unverified. JD region/stock changes by destination; do not map seller location to delivery eligibility. |
| Condition | Web quick toggle `全新`; client serializes `propValueStr.searchFilter="quickFilter:filterNew;"`; also `filterPersonal` and `filterFreePostage`. Item details can display more granular `成色` and `拆修`. No verified server-side used-condition enum or exact laptop-model facet. | Condition facet codes unverified; filter only explicitly returned attributes locally and mark unknown otherwise. |
| Pagination | Client defines `pageNumber` default 1 and `rowsPerPage` default 30; native search yielded 1/1 for this session. Do not assert empty results are exhaustive. | Taobao source documents `page` 1-based, and `tab=mall` for Tmall. JD pagination contract unverified. |

These are **third-party observed implementation contracts**, not an official stable public API, nor proof they work without authentication. The [OpenCLI source](https://github.com/jackwener/OpenCLI/blob/97dc0cd5214b9602bcda78d7422f231ee8a803e9/clis/xianyu/search.js) uses `mtop.taobao.idlemtopsearch.pc.search` with browser `window.lib.mtop.request`, `needLogin:false` and `needLoginPC:false`, but its documented prerequisite is a logged-in browser and its code stops for login or verification. The [client builder](https://github.com/11273/goofish-client/blob/30b153653588d4d4e1d9038290b1e968525e5be4/src/services/mtop/builders/search-params.builder.ts) joins `priceRange`, `publishDays`, and `quickFilter` with semicolons and JSON-serializes location. Its [service](https://github.com/11273/goofish-client/blob/30b153653588d4d4e1d9038290b1e968525e5be4/src/services/mtop/search.service.ts) identifies another mtop search API; do not assume API names and schemas are interchangeable. Both projects rely on session/cookie infrastructure; a flag named `needLogin:false` is not evidence that the server grants guest search.

## Account trade-off and foreign numbers

[Taobao's overseas privacy policy](https://terms.alicdn.com/legal-agreement/terms/privacy_policy_full/20240717202714454/20240717202714454.html) expressly contemplates accounts registered with an overseas mobile number, and overseas users registered by email or third-party account in applicable circumstances. It also identifies passports among possible identity data for verification, customs and other purposes. This is meaningful evidence of support for some overseas users, **not confirmation that Brazil +55 currently works**, that SMS will arrive, that Goofish accepts the same account without further checks, or that a Chinese national ID is universally required. JD's [registration help](https://help.jd.com/user/issue/945-4268.html) describes account information and phone/email verification; a current +55 option and successful registration were not established. No account creation was attempted.

A functioning account could unlock native keyword results, server-side filtering, saved searches and, where permitted, direct seller interaction; these are practical possibilities, not promised entitlements. Fansbuy can instead accept a product link and its guide offers name search across specified marketplaces, acting as purchasing intermediary; it does not by itself establish access to every Goofish listing, native seller messaging, complete search/filter parity, final stock, exportability, shipping costs or a completed transaction. Confirm those per item with the agent's own interface before relying on them.
