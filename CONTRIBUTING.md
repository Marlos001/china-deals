# Contributing

Keep adapters read-only, preserve source IDs and native currencies, and return explicit login/block/unknown states. Never turn synthetic data, an affiliate pool or an empty response into proof of full marketplace access.

Run `python -m unittest discover -s tests -v` before submitting. Changes affecting money, source contracts or command execution need focused tests. Label mock, captured and live evidence separately. Do not add live-network requirements to unit tests.

Research claims should link primary sources and pinned repository revisions. Explain licensing before importing upstream code. Avoid automatic CAPTCHA solving, credential collection, hidden AI calls or transaction commands. Do not commit cookies, profiles, private captures, tokens or user searches.
